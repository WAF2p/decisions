## Summary

The WAF++ PASS platform code and test coverage are fragmented across wafpass-core, wafpass-server, and wafpass-dashboard. This RFC proposes a unified test/quality coverage plan: shared coverage gates, golden-file E2E fixtures, and consistent CI reporting.
